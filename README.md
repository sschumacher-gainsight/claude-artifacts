# claude-artifacts

Standardized hosting for self-contained HTML artifacts generated by Claude.

## Convention

Each artifact lives in its own subfolder with `index.html` as the entry point:

```
claude-artifacts/
├── index.html                          # landing page (lists all artifacts)
├── README.md
└── <artifact-slug>/
    ├── index.html                      # the artifact
    └── README.md                       # optional context / description
```

## URL format

```
https://sschumacher-gainsight.github.io/claude-artifacts/<artifact-slug>/
```

GitHub Pages serves files with the correct `Content-Type`, so HTML renders natively in any browser without preview shims.

## Adding a new artifact

1. Create `<artifact-slug>/index.html`
2. (Optional) Add `<artifact-slug>/README.md` with context
3. Append a row to `index.html` so it shows up on the landing page
4. Commit and push — Pages rebuilds in ~30 seconds
